SHADOWROCKET · SIDESTORE

分流与去广告，
一次导入。

使用 Shadowrocket 提供本机回环，同时更新分流与去广告规则。SideStore 需配好有效配对文件，并把实际设备地址固定为 10.7.0.1。

一键导入到 Shadowrocket ↗

请在 iPhone 的 Safari 中打开。Shadowrocket 将提示你安装此模块。

首次使用

  1. 在 Shadowrocket 选择本地 default.conf，全局路由设为“配置”。
  2. 点击上方按钮，安装并启用模块。
  3. 为 SideStore 续签：到 Shadowrocket“设置 → 其它”，开启 Include Route 10.7.0.1/32；同时按下方说明在本地基础配置中保留默认路由，保存后断开重连 VPN。续签时连接 Wi-Fi。
  4. 在新版内置 SideStore“Settings → Connection Configuration”中，关闭 Use Local VPN，在 Remote Endpoint → Device IP 填入 10.7.0.1，RemotePair Port 留空，点击 Confirm。此处只切换 SideStore 的连接模式，Shadowrocket 继续连接。
  5. 为 HTTPS 重写：在当前配置的“HTTPS 解密”里生成、安装 CA，再到 iOS 的“证书信任设置”中信任它。这一步与续签独立。

旧合并版可能自动连到 198.18.0.2，且没有可编辑的设备地址。官方 Nightly 合并版 LiveContainer 3.8.11 / SideStore 0.7.0 提供上述设置。其本机 VPN 自动识别仍可能清空端点，因此这里使用 Remote Endpoint。升级前请备份数据，再分别测试手动刷新与重连后的刷新。

保留默认路由，兼顾 TG 和续签

在“配置”页打开当前勾选的本地基础配置 → 编辑纯文本，在已有的 [General] 段内添加或修改下面这一行；已有段标题时不要重复添加：

[General]
tun-included-routes = 0.0.0.0/0,10.7.0.1/32

0.0.0.0/0 保留 IPv4 互联网默认路由，10.7.0.1/32 保留续签地址的具体路由。原生 Include Route 10.7.0.1/32 开关继续开启。保存并重连 VPN，全局路由使用“配置”。

2026-11-06 实测：TG 一直“连接中”、全局代理也无效时，日志显示默认路由缺失。补上这一行后默认路由恢复，用户确认“配置”模式下 TG 和续签快捷指令都成功。尚未确定应用最初省略默认路由的原因。

这是本地基础配置的设置。只更新模块不会自动补上这行；请保留原有 CA 和其他设置，包含路由不要只填 10.7.0.1/32。

每日自动续签

新建快捷指令“LiveContainer 自动续签”，依次添加：

  1. 设置 VPN：连接 Shadowrocket。
  2. 等待 5 秒。
  3. LiveContainer：刷新所有 App / Refresh All Apps。

先手动运行，确认到期时间更新；再添加“特定时间 → 每天 → 立即运行”自动化，并测试锁屏执行。

每日续签与下方的规则自动更新分别配置。两者都只使用 Shadowrocket 作为 VPN。

2026-11-02 已验证上述版本组合的普通 Refresh 和手动续签快捷指令成功；2026-11-06 补足默认路由后再次确认 TG 与手动续签同时成功。定时、锁屏执行仍需检查下一次运行结果。

提示配对文件无效或缺失？

用 USB 连接并解锁 iPhone。在电脑 iloader 中打开“管理配对文件”，找到 LiveContainer，点击“放置”。完全退出再重开 LiveContainer 后重试。

VPN 模块不能生成配对文件。文件已经导入但仍提示无效时，需要重新配对这台设备。

规则自动更新

在 Shadowrocket 的“设置 → 自动更新 → 模块”中选择每天更新，并允许后台 App 刷新。证书随本地 default.conf 保留。

MITM 默认作用于 Google CN 跳转域名。IPA 的签名、配对与刷新由你使用的 SideStore / 签名工具完成。

early eof 或 DDI Not Mounted？

先检查 SideStore 实际连接地址。旧版可能误选 198.18.0.2；新版的 Use Local VPN 模式在接口识别失败时也可能清空设备端点。按上文使用 Remote Endpoint，固定为 10.7.0.1。若仍失败，再检查配对和开发者服务。

安装证书已被撤销？

确认当前 SideStore 持有有效证书后，在 My Apps 长按 LiveContainer，选择 Resign。扩展提示选择 Keep App Extensions (Use Main Profile)。重签安装完成后再测试 Refresh。
