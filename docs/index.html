SHADOWROCKET · SIDESTORE

分流、去广告与续签，
一份完整配置。

默认路由、SideStore 续签地址、分流、去广告和 Google CN 重写一起同步更新。直接导入配置，无需单独安装规则模块。

一键导入完整配置 ↗

请在 iPhone Safari 打开。下载后选择 Shadowrocket-SideStore.conf → 使用配置。节点需使用你自己的订阅。

首次使用

  1. 点击上方按钮，下载并使用 Shadowrocket-SideStore.conf，全局路由设为“配置”，选择有效节点。
  2. 用过旧规则模块时，先停用 Shadowrocket-SideStore.sgmodule 和早期增强模块，原有成功配置保留作备份。
  3. 为 SideStore 续签：到 Shadowrocket“设置 → 其它”，开启 Include Route 10.7.0.1/32。完整配置已内置默认路由参数；使用后断开重连 VPN，续签时连接 Wi-Fi。
  4. 在新版内置 SideStore“Settings → Connection Configuration”中，关闭 Use Local VPN，在 Remote Endpoint → Device IP 填入 10.7.0.1，RemotePair Port 留空，点击 Confirm。此处只切换 SideStore 的连接模式，Shadowrocket 继续连接。
  5. 需要 MITM 时，按下方说明扩展为本地配置后再添加证书，保留证书与规则自动更新。续签本身不依赖 MITM。

旧合并版可能自动连到 198.18.0.2，且没有可编辑的设备地址。官方 Nightly 合并版 LiveContainer 3.8.11 / SideStore 0.7.0 提供上述设置。其本机 VPN 自动识别仍可能清空端点，因此这里使用 Remote Endpoint。升级前请备份数据，再分别测试手动刷新与重连后的刷新。

内置路由，兼顾 TG 和续签

完整配置已包含下面的参数，每日同步上游时也会保留：

[General]
tun-included-routes = 0.0.0.0/0,10.7.0.1/32

0.0.0.0/0 保留 IPv4 互联网默认路由，10.7.0.1/32 保留续签地址的具体路由。原生 Include Route 10.7.0.1/32 开关仍需开启。使用配置后重连 VPN，测试 TG 和续签。

MITM 证书留在手机

远程更新会覆盖配置中的本地修改。需要 MITM 时，使用“扩展配置”保留 CA，无需证书模块：

  1. 点击已导入的远程完整配置 → 扩展配置，新建本地 SideStore-Local.conf。
  2. 确认本地扩展配置“通用 → 包含配置”指向远程完整配置，本地文件不设置 update-url。
  3. 在本地扩展配置“HTTPS 解密 → 证书”粘贴已有 CA，或生成并安装 CA，再到 iOS“证书信任设置”信任它。
  4. 使用本地扩展配置；以后更新远程原配置，本地文件保留证书和个人设置。

首次设置后，手动更新一次远程原配置，再使用本地扩展配置，确认 CA、TG 和续签正常。不使用 MITM 时可直接使用远程完整配置。

每日自动续签

新建快捷指令“LiveContainer 自动续签”，依次添加：

  1. 设置 VPN：连接 Shadowrocket。
  2. 等待 5 秒。
  3. LiveContainer：刷新所有 App / Refresh All Apps。

先手动运行，确认到期时间更新；再添加“特定时间 → 每天 → 立即运行”自动化，并测试锁屏执行。

每日续签与下方的规则自动更新分别配置。两者都只使用 Shadowrocket 作为 VPN。

提示配对文件无效或缺失？

用 USB 连接并解锁 iPhone。在电脑 iloader 中打开“管理配对文件”，找到 LiveContainer，点击“放置”。完全退出再重开 LiveContainer 后重试。

VPN 模块不能生成配对文件。文件已经导入但仍提示无效时，需要重新配对这台设备。

完整配置每天同步

仓库每天北京时间 08:30 左右同步上游，生成完整配置。手机在“设置 → 自动更新 → 配置”启用自动后台更新，间隔设为 1 天，并允许后台 App 刷新。

首次先点击远程配置 → 更新配置。使用本地扩展时，检查远程原配置是否已更新；若未刷新，手动更新原配置后重新使用本地扩展配置。

仓库同步和手机拉取是两步。配置继承与后台调度需检查下一次运行结果；旧模块地址继续兼容维护，新安装只需完整配置。

MITM 默认作用于 Google CN 跳转域名。IPA 的签名、配对与刷新由你使用的 SideStore / 签名工具完成。

early eof 或 DDI Not Mounted？

先检查 SideStore 实际连接地址。旧版可能误选 198.18.0.2；新版的 Use Local VPN 模式在接口识别失败时也可能清空设备端点。按上文使用 Remote Endpoint，固定为 10.7.0.1。若仍失败，再检查配对和开发者服务。

安装证书已被撤销？

确认当前 SideStore 持有有效证书后，在 My Apps 长按 LiveContainer，选择 Resign。扩展提示选择 Keep App Extensions (Use Main Profile)。重签安装完成后再测试 Refresh。
